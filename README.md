# Lista-jednokierunkowa-w-C-odczyt-i-zapis-plik-w-tekstowych
Program napisany w języku C++, który odczytuje dane z pliku tekstowego dane.txt, zapisuje każdą linię jako osobny element listy jednokierunkowej, wyświetla zawartość listy w konsoli oraz zapisuje ją do pliku wynik.txt. Program wykorzystuje dynamiczną alokację pamięci i zwalnia ją po zakończeniu działania.
